# Лабораторная работа №1: Система учета складских запасов

Курсовой сквозной проект по дисциплине **«Разработка серверных приложений»**.  
**Вариант №12:** Система учета складских запасов (*Inventory Management*).

---

## Описание

Серверное приложение для автоматизации работы склада. Система помогает вести учет поступления и отгрузки товаров, контролировать остатки по ячейкам хранения и вовремя предупреждать о заканчивающихся позициях для заказа у поставщиков.

**Пользователи системы:**
* **Кладовщик:** приемка, отгрузка, перемещение по полкам и инвентаризация через мобильный терминал (ТСД).
* **Аналитик закупок:** контроль остатков через веб-интерфейс, настройка порогов и оформление заказов поставщикам.
* **Администратор:** управление складами, категориями и номенклатурой.

---

## Стек технологий

* **Клиент (Web):** React, TypeScript
* **Клиент (Mobile):** Flutter (приложение для терминалов сбора данных ТСД)
* **Серверная часть (Backend):** Node.js / Express (или Go)
* **База данных:** PostgreSQL (схема в 3NF, первичные ключи UUID)
* **Кэш и очереди:** Redis
