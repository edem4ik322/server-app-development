## 📌 Описание работы

В рамках данной лабораторной работы спроектирован REST API интерфейс для клиент-серверного взаимодействия системы складского учета (WMS). 

API строго следует канонам REST:
* Именование сущностей существительными во множественном числе;
* Использование семантически корректных HTTP-методов (`GET`, `POST`, `PATCH`, `DELETE`);
* Разграничение прав доступа по ролям (`STOREKEEPER`, `PROCUREMENT_ANALYST`, `ADMIN`);
* Использование статус-кодов ответов (`200`, `201`, `204`, `400`, `401`, `403`, `404`, `409`);
* Единая структура объекта ошибок `ErrorResponse` для всех непредвиденных ситуаций и бизнес-конфликтов (включая защиту от отрицательных остатков).

## 📂 Структура проекта

* [openapi.yaml](./openapi.yaml) — валидная спецификация REST API по стандарту **OpenAPI 3.0.3** (Swagger).
* [ARCHITECTURE.md](./ARCHITECTURE.md) — подробный архитектурный отчет:
  * Описание предметной области и Use Cases;
  * Диаграммы C4 Containers и ERD (3NF) с адресным хранением и UUID;
  * Сводная таблица 8 REST-эндпоинтов;
  * Описание статус-кодов и единой схемы ошибок;
  * Развернутые ответы на 5 контрольных вопросов для защиты.
* [diagrams/](./diagrams/) — исходные коды Mermaid (`.mmd`) и растровые изображения (`.png`) архитектурных диаграмм.

## 🚀 Как посмотреть документацию Swagger UI

Спецификацию можно интерактивно просмотреть и протестировать несколькими способами:

### Способ 1. Онлайн через Swagger Editor (самый простой)
1. Откройте в браузере [editor.swagger.io](https://editor.swagger.io).
2. Выберите в верхнем меню **File -> Import file** и загрузите файл `openapi.yaml` (или просто скопируйте его содержимое в левое окно).
3. В правой панели сразу отобразится готовый интерактивный интерфейс Swagger UI со всеми эндпоинтами, параметрами и схемами данных.

### Способ 2. В VS Code / Antigravity
Установите расширение **OpenAPI (Swagger) Editor** или **Swagger Viewer** и нажмите сочетание клавиш `Shift + Alt + E` (или кнопку предпросмотра Swagger в верхнем правом углу файла `openapi.yaml`).
